# gcam-claude-plugins

Claude Code plugins for GCAM work.

| Plugin | What it does |
|---|---|
| [gcam-progress](plugins/gcam-progress) | A band above the prompt that follows running GCAM jobs (period, iterations, elapsed time, ETA, unsolved years). `/gcam-progress` prints the full table. |

Install from Claude Code:

```
/plugin install gcam-progress --marketplace jiheunha/gcam-claude-plugins
```

or from a shell:

```
claude plugin install gcam-progress --marketplace jiheunha/gcam-claude-plugins
```

See the [plugin's README](plugins/gcam-progress/README.md) for what it shows and how to configure it.
